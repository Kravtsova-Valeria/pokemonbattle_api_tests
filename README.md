# pokemonbattle_api_tests



## Описание

Данный проект содержит автоматизированные тесты для API Pokemon Battle.

## Структура

### Почему выбрана структура представленная ниже 

- **Разделение ответственности** — каждый компонент проекта находится в своей папке: тесты в tests, конфигурация в config, данные в data, фикстуры в fixtures. Это делает проект легко поддерживаемым и масштабируемым.

- **Переиспользование фикстур** — фикстуры вынесены в отдельный каталог и подключены через conftest.py, что делает их доступными во всех тестах без необходимости импорта в каждом файле.

- **Безопасность** — токен хранится в .env и не попадает в репозиторий, что исключает утечку данных.

- **Удобство работы с тестовыми данными** — константы вынесены в data/api_constants.py, что позволяет легко изменять их без правки самих тестов.

- **Готовность к расширению** — папки helpers и schemas оставлены для будущего масштабирования.

### Корневые файлы

- **conftest.py** — глобальная конфигурация pytest. Здесь подключаются фикстуры из папки fixtures.

- **pytest.ini** — настройки pytest. Здесь определяются маркеры для группировки тестов (например, @pytest.mark.trainers, @pytest.mark.pokemons).

- **requirements.txt** — список зависимостей проекта (pytest, requests и их зависимости).

- **.env** — файл с переменными окружения. Здесь хранится токен авторизации. Файл добавлен в .gitignore, чтобы данные не попадали в репозиторий.

- **.gitignore** — список файлов и папок, которые не отслеживаются git (venv, .env и другие).

- **README.md** — документация проекта.

### Папка config

Содержит конфигурационные файлы проекта. Вынесены в отдельную папку, чтобы при изменении URL или других настроек не пришлось править тесты.

- **api_config.py** — базовые URL для API.

### Папка data

Содержит тестовые данные и константы. 

- **api_constants.py** — константы для тестов. 

### Папка fixtures

Содержит pytest-фикстуры. Вынесены в отдельную папку для переиспользования во всех тестах. Фикстуры подключаются через conftest.py.

- **api_fixtures.py** — фикстуры для работы с API:
  - `trainer_get_session` — сессия для GET-запросов (без авторизации)
  - `pokemon_patch_session` — сессия для авторизованных запросов (с токеном)

### Папка helpers

Для расширения функциональности в будущем.

### Папка schemas

Предназначена для JSON-схем валидации ответов API. Для расширения функциональности в будущем. 

### Папка tests

Содержит файлы с тестами. Вынесены в отдельную папку для разделения кода тестов и вспомогательного кода.

### Папка venv

Виртуальное окружение Python. Не отслеживается git.
